# 依頼文テンプレート

ここにある `*.md` は MCP サーバーの **プロンプト** として登録され、AI クライアントのメニューから選べる
(Claude Desktop: 入力欄の「＋」、Claude Code: `/mcp__jh-presentation__<ファイル名>`、VS Code: `/`)。

- チームや個人のテンプレートは **ワークスペースの `prompts/`** に置く (同じファイル名なら上書き)
- ファイル名は英数字とハイフン (`my-template.md`)。`_` で始まるファイルは読み込まない
- 追加・変更したら MCP サーバーを再起動 (クライアントを再起動) すると反映される

```markdown
---
title: メニューに出る名前
description: 説明
args:
  topic: 引数の説明 (必須)
  minutes: 持ち時間 (分) (任意)
---
本文。{{topic}} で引数を埋め込む。{{minutes|30}} は未指定時に 30 になる。
説明に「(任意)」を含む引数は省略できる。
```
