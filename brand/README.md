# ブランド設定 (名前・ロゴ)

`brand.json` とロゴ画像をこのフォルダに置くと、デッキの上下の帯・表紙に名前とロゴが入る。
(MCP のワークスペースでは `<ワークスペース>/brand/`。最初は同梱のサンプルがコピーされる)

```json
{
  "name": "Your Name",            // 名前 (個人名・チーム名など。空なら出さない)
  "label": "DRAFT",                // 右側のラベル (空なら出さない)
  "logo": "logo.png",              // ロゴ画像 (png / svg / jpg。高さ 36px 程度で表示)
  "position": "none"               // 新規デッキの既定: none / header / footer / both
}
```

- デッキごとの表示位置は、作成時やあとから `brand` で指定できる (例:「ブランド枠を下に入れて」)
- ロゴは横長でも正方形でもよい。背景が透明な PNG か SVG を推奨
- 変更は次にデッキを書き込んだとき (または upgrade) に反映される
